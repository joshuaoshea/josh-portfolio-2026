# About Page Images

This folder contains images used on the About page.

## Image Files

Add your About page images here. Common images might include:

- Profile photo or hero image
- Personal photos
- Any other images specific to the About page

## Usage

Images in this folder can be referenced in the About page component using:
```
/images/about/your-image-name.png
```

## Recommended Formats

- PNG with transparent background (if needed)
- JPG/JPEG for photos
- SVG for scalable graphics

## Image Optimization

For best performance, consider:
- Optimizing images before adding them
- Using appropriate file sizes for web
- Maintaining aspect ratios as needed
