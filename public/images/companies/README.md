# Company Logos

This folder contains company logo images used on the About page.

## Required Logos

Please add the following logo images:

- `zendesk.png` (or `.svg`) - Zendesk company logo
- `genesys.png` (or `.svg`) - Genesys company logo  
- `sap.png` (or `.svg`) - SAP company logo

## Image Specifications

The logos will be displayed in rounded cards with the following dimensions:
- Card size: 351.393px × 186.537px
- Logo container: ~222px × ~135px (varies by logo)
- Border radius: 33.644px
- Background: #fefaf6
- Border: #dedede (0.898px solid)

## Recommended Format

- PNG with transparent background, or
- SVG for scalability

The logos should be centered within their containers and sized appropriately to fit the card dimensions.
